# Sketch Manifest

## Design Direction

OSCAR CorrTest is a dense engineering console for technical OSCAR operators. It should expose rule, label, evidence, target, and execution details directly; use compact layouts and precise language; and keep technical reference material close to the controls without turning the workflow into a beginner-oriented wizard. The visual vocabulary follows OTTO Gateway's dark/light operator console and the existing CorrTest yellow, purple, green, orange, and red status palette.

## Reference Points

- OTTO Gateway admin console: dark/light theming, dense operational panels, live log controls.
- Existing OSCAR CorrTest UI: fixed header, left navigation, compact cards and tables, monospaced identifiers.
