# Sketch 001: Console Structure and Guidance

## Design Question

How should global navigation, dense technical content, and page-specific operational guidance coexist without consuming the workspace needed for OSCAR correlation details?

## How to View

```bash
open .planning/sketches/001-console-structure-guidance/index.html
```

## Variants

- **A: Reference Rail** — persistent technical reference beside the working area.
- **B: Inline Contract** — compact page contract and expandable reference blocks within a wider workspace.
- **C: Documentation Drawer (selected)** — maximum working width with technical guidance available from a right-side drawer.

## What to Look For

- Whether guidance is visible enough without competing with work.
- Whether the scenario table and OSCAR identifiers remain comfortably scannable.
- Whether navigation remains usable at tablet widths.
- Whether the interface feels like an engineering console in both themes.
