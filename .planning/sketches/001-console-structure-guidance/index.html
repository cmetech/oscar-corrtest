Technical reference

Scenario catalog

What this page controls

Scenario sources are local immutable definitions. Viewing and compiling do not contact OSCAR. Starting a run creates a namespaced rule, injects alerts, gathers evidence, and removes owned resources.

Required document shape

apiVersion: corrtest.oscar/v1alpha1
kind: CorrelationScenario
name: flood-basic
suite: builtin-all
pattern: flood
maxDuration: 90s
cases: [P01, N01]

Identity labels

  • alertname: CORRTEST_<PATTERN>_<CASE>_<ROLE>_<RUN>
  • category: corrtest_<pattern>
  • oscar_test_run_id: full run identifier
  • oscar_test_pattern: normalized pattern
